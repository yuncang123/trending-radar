# Trending Radar

可配置、可开源的 Obsidian 趋势采集与日报草稿插件。

## 职责

- 手动抓取 RSS、手动 URL、GitHub、Hacker News 和可配置中文来源。
- 规范化、确定性去重、核查、筛选并生成 Markdown 日报。
- 按源保存运行结果，显式记录部分失败、取消和中断。
- 支持模板 Writer，以及外部 Agent Skill 接管写作。

## 组合关系

共享 artifact 契约、fixture 和兼容矩阵由 `secondbrain-toolkit` 维护。本仓库只维护插件实现、测试、示例 Profile 和 Trending Radar Writer companion。
